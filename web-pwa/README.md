# Веб-версия CoolRead (PWA)

Та же читалка, что и в APK, но как сайт, который можно «установить»:
- Windows и Mac: Chrome или Edge → значок «Установить» в адресной строке;
- iPhone и iPad: Safari → «Поделиться» → «На экран Домой»;
- Mac в Safari: «Файл» → «Добавить в Dock».

После первого открытия приложение работает без интернета. Книги хранятся в браузере
на этом устройстве (с телефоном они не синхронизируются).

## Сборка

```
npm run build:web     # готовый сайт в dist-web/
```

Сборка APK (`npm run android:cool` и т. п.) эту папку не использует.

Что здесь лежит:
- `public/` — манифест, значки; при веб-сборке копируется в `dist-web/`;
- `sw.template.js` — service worker; сборка вписывает в него список всех файлов для офлайн-работы;
- `cors-proxy/worker.js` — посредник для каталогов (см. ниже).

Публикацию на GitHub Pages делает `.github/workflows/deploy-web.yml` при каждом push в `main`.

## Чем веб-версия отличается от Android

- **Каталоги** (OPDS, az.lib.ru, MangaDex): браузер не даёт сайту читать чужие сайты,
  поэтому нужен посредник — Cloudflare Worker из `cors-proxy/worker.js`. Без него работает
  только каталог lscnsk (он на GitHub), а кнопки «➕ catalog» нет; с посредником каталоги
  добавляются так же, как в приложении.
- **Озвучка**: тот же голос Silero, что и в APK, работает прямо в браузере (`utils/silero/`).
  Как и в приложении, он скачивается один раз при первом включении (около 100 МБ) и хранится
  в браузере; после этого работает без интернета. Где браузер его запустить не может,
  используются голоса самого устройства. С выключенным экраном браузер чтение не продолжает.
- **Встроенного браузера с кнопкой 📥 нет**: сайты открываются в новой вкладке.
- **Открыть с помощью**: на компьютере установленное приложение регистрируется для fb2, epub,
  pdf, cbz, cbr, mp3, m4b (Chrome/Edge).

## Посредник для каталогов (Cloudflare Worker, бесплатно)

1. Зарегистрироваться на https://dash.cloudflare.com → Workers & Pages → Create → Worker.
2. Назвать, например, `coolread-proxy`, нажать Deploy, затем Edit code, вставить весь
   `cors-proxy/worker.js`, Deploy.
3. Settings → Variables: добавить `ALLOWED_ORIGIN` = адрес сайта, например `https://name.github.io`.
4. В репозитории GitHub: Settings → Secrets and variables → Actions → вкладка Variables →
   New variable: `CORS_PROXY` = `https://coolread-proxy.<ваше-имя>.workers.dev/?url=`
5. Перезапустить публикацию: Actions → Deploy web version → Run workflow.

## Lite-версия для Telegram (мини-приложение)

Та же веб-версия (чтение вслух голосом Silero тоже есть), но без каталога az.lib.ru
и без встроенного браузера:
сайты открываются в браузере Telegram. Кнопка «Назад» Telegram закрывает открытое (книгу,
каталог, оглавление), шапка Telegram окрашивается в цвет стиля приложения, свайп вниз
не закрывает приложение во время чтения.

```
npm run build:telegram   # готовый сайт в dist-telegram/
```

Публикация: тот же `deploy-web.yml` кладёт lite-версию в папку `tg/` сайта,
то есть адрес будет `https://<имя>.github.io/coolread/tg/`.

Подключение к боту:
1. В Telegram открыть @BotFather → `/newbot`, придумать имя и адрес бота.
2. `/newapp` → выбрать бота, указать название, описание, картинку 640×360,
   адрес `https://<имя>.github.io/coolread/tg/` и короткое имя, например `read`.
3. Готово: приложение открывается по ссылке `https://t.me/<бот>/read`.
   Чтобы кнопка была прямо в чате с ботом: `/mybots` → бот → Bot Settings → Menu Button.

Ссылка на конкретную книгу lscnsk: `https://t.me/<бот>/read?startapp=book_<id>`
(как `#book=<id>` в веб-версии).

## Бот с карточками книг (Cloudflare Worker, бесплатно)

`telegram-bot/worker.js` — программа бота. Он присылает «красивые» сообщения Telegram
(rich messages): карточку книги с обложкой, автором, описанием и кнопкой «Читать в CoolRead»,
которая сразу открывает эту книгу в мини-приложении. Короткие книги и сборники рассказов
можно читать прямо в чате: «Читать здесь» → содержание → части по 15–20 страниц с кнопкой
«Дальше». У больших романов в чате только начало, дальше — в приложении.

Что умеет бот:
- `/start` и `/books` — все книги каталога lscnsk, у каждой кнопка с карточкой;
- написать название, автора или рассказ («прибрежный пират») — бот пришлёт карточку;
- ссылка на карточку для соцсетей: `https://t.me/<бот>?start=book_<id>`.

Книги, обложки и нарезанные части бот берёт из репозитория lscnsk_library
(`catalog.json`, `covers/`, `telegram/`), так что новая книга появляется в боте сама,
через пару минут после загрузки fb2.

Как запустить:
1. Ключ бота: в Telegram открыть @BotFather → `/mybots` → ваш бот → API Token → скопировать.
   Никому его не пересылайте и не кладите в репозиторий.
2. https://dash.cloudflare.com → Workers & Pages → Create → Worker (Start with Hello World).
   Назвать, например, `coolread-bot`, нажать Deploy.
3. Edit code → удалить всё, вставить весь `telegram-bot/worker.js` → Deploy.
4. Settings → Variables and Secrets → Add: Type **Secret**, Name `BOT_TOKEN`,
   Value — ключ из шага 1 → Deploy.
   Если короткое имя мини-приложения в `/newapp` было не `read`, добавить ещё
   Type Text, Name `APP_NAME`, Value — это имя.
5. Открыть в браузере `https://coolread-bot.<ваше-имя>.workers.dev/setup`.
   Должна появиться страница «Готово» с именем бота.
6. В Telegram открыть бота и нажать «Запустить» (или написать `/books`).

Если что-то не так: в Cloudflare у воркера вкладка Logs → Begin log stream, затем
написать боту; там видно, что ответил Telegram.
